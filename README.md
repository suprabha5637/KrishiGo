# 🌾 About KrishiGo

**KrishiGo** is an AI-powered agricultural technology platform designed to connect **farmers, agricultural intelligence, farm management, and consumers** within a unified digital ecosystem.

The platform combines two major experiences:

> 👨‍🌾 **Farmer Intelligence**
> 🛒 **Agri-Commerce**

KrishiGo is designed around the idea that agriculture should not be treated as a collection of disconnected tools.

The platform brings together:

* 🌦️ Weather & Climate Intelligence
* 🌱 Crop Planning
* 🦠 Crop Health & Disease
* 🌍 Soil & Field Intelligence
* 💧 Water & Irrigation
* 🚜 Farm Management
* 💰 Market Price & Profit
* 📡 Farm Monitoring
* 🛠️ Farm Services
* 🤖 AI Farm Copilot
* 📚 Agricultural Learning
* 🛒 Hyperlocal Agri-Commerce

# ⚡ Getting Started

## Prerequisites

Install:

* Node.js
* npm
* Python 3
* Git

Verify:

```bash
node --version
npm --version
python3 --version
git --version
```

---

# 📥 Clone the Repository

```bash
git clone https://github.com/suprabha5637/KrishiGo.git
cd KrishiGo
```

---

# 🎨 Frontend Setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Configure the required environment variables inside `.env`.

---

# 🐍 Backend Setup

Open a new terminal:

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Start the backend using the project's configured application entry point.

---

# 🔐 Environment Variables

Never commit real credentials to GitHub.

Use:

```text
.env
```

for local secrets.

Use:

```text
.env.example
```

as the safe configuration template.

Never commit:

```text
.env
service-account.json
firebase-adminsdk*.json
*.db
*.sqlite
*.sqlite3
```
